# Campus Mate PRD (초안)

## 1. 누구를 위해 (Target Users)
- 대학생: 강의 일정, 과제, 시험, 동아리 활동이 불규칙하게 반복되는 18~25세 사용자
- 특히 스마트폰으로 아침에 하루 일정을 확인하고, 수업 사이 짜투리 시간에 할 일을 처리하는 패턴이 많은 사용자

## 2. 왜 (Problem / Motivation)
- 대학생은 할 일(과제, 리포트, 시험 준비)과 외부 정보(날씨, 옷차림, 우산 필요 여부)를 여러 앱/메모에 흩어져 관리함
- 매일 아침 "오늘 뭐 해야 하지?"를 한 화면에서 빠르게 파악할 수 있는 도구가 없음
- 정보가 여러 곳에 분산되어 중요한 일을 놓치거나, 날씨를 확인하지 않아 우산을 안 가져가는 등의 불편 발생

## 3. 핵심 기능 (Core Features)
1. **할 일 관리**: 과제·약속·공부 등 할 일을 추가하고, 오늘/이번 주 마감 기준으로 정렬. 완료 체크와 간단한 리마인더 제공
2. **오늘의 날씨 알림**: 앱을 열면 오늘의 날씨(기온, 강수 여부, 미세먼지 등)를 요약해 보여주고, 우산·외투가 필요하면 알림
3. **[내가 고른 기능]**: ← 사용자가 직접 선택해 채울 항목 (예: 시간표 연동, 집중 타이머, 카페 추천 등)

## 4. 하지 않을 것 (Out of Scope)
- 소셜/커뮤니티 기능(친구 피드, 채팅 등)
- 결제·광고·수익화 기능
- 대학 공식 시스템(포털, LMS)과의 데이터 연동 (초기 버전)
- Android/iOS 네이티브 앱 — 초기 버전은 웹으로 제공

## 5. 성공 기준 (Success Criteria)
- **DAU**: 출시 4주 후 주간 활성 사용자(DAU)의 30% 이상이 주 5일 이상 사용
- **할 일 등록률**: 활성 사용자 1인당 주간 평균 3개 이상 할 일 등록
- **날씨 확인율**: 활성 사용자의 50% 이상이 주 3회 이상 날씨 알림을 확인
- **리텐션**: 출시 2주 후 D1 리텐션 40% 이상, D7 리텐션 20% 이상
- **만족도**: 사용자 피드백/설문 기준 "매일 아침 확인하고 싶다" 응답 60% 이상
